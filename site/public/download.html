Download for macOS

Requires macOS 13 or later. Signed and notarized by Apple, so it opens without any security warnings.

Setting up

  1. Open the downloaded file and drag Closiq Sync to Applications.
  2. Open it once. It will offer to take you straight to Safari's extension settings.
  3. Turn on Closiq Sync under Extensions.
  4. Click the Closiq Sync button in Safari's toolbar and choose Always Allow on Every Website.
  5. Reload any tab you already had open.

That last step matters more than it sounds. Safari does not add an extension to pages that were already open when you granted access.

Watching together

  1. Open the video and click the toolbar button, then Start a session.
  2. Send the six-character code to the other person.
  3. They open the same video and enter the code.

Want to check it works first? Open the test clip on both Macs. It has a timer burned into the picture, so when you are in step both screens show the same number.
